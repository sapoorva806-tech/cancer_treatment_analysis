# Hodgkin Lymphoma Risk Prediction & Health Analytics Platform

An educational/research full-stack platform that estimates Hodgkin lymphoma
risk from user-reported symptoms using a PyTorch neural network. Built for
a college project.

> **Disclaimer:** This platform is an educational/research tool and does
> not provide a medical diagnosis. Predictions are generated by a
> machine-learning model based on the information provided and should not
> be used as a substitute for professional medical advice or diagnostic
> testing.

## Tech Stack

- **Frontend:** HTML5, Tailwind CSS, vanilla JavaScript, Chart.js
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic, JWT auth
- **Database:** PostgreSQL, Alembic migrations
- **ML:** PyTorch, scikit-learn, pandas, NumPy
- **Containerization:** Docker, Docker Compose
- **Testing:** pytest

## Running Locally (without Docker)

See setup details in earlier project history / commit messages. Summary:
1. `cd backend && pip install -r requirements.txt`
2. Set up PostgreSQL, create `.env` with `DATABASE_URL`, `JWT_SECRET`
3. `alembic upgrade head`
4. `uvicorn app.main:app --reload`
5. Serve `frontend/` with `python -m http.server 5500` (from the `frontend`
   folder, so paths resolve — open `http://localhost:5500/pages/register.html`)

## Running with Docker (recommended)

```bash
docker compose up --build
```

On first run only, apply migrations:
```bash
docker compose exec backend alembic upgrade head
```

Then visit:
- Frontend: http://localhost:5500/pages/register.html
- Backend docs: http://localhost:8000/docs

## Training the ML Model

```bash
cd ml/data && python generate_dummy_data.py   # synthetic data for testing the pipeline
cd ../preprocessing && python preprocess.py    # verify preprocessing works
cd ../training && python train.py               # trains and saves the model
```

**Note:** The bundled model is trained on **synthetic data** for pipeline
demonstration only — see `ml/data/README.md`. It has no medical validity.
Replace `ml/data/dataset.csv` with a real, properly licensed dataset before
treating any prediction or metric as meaningful.

## Running Tests

```bash
cd backend
python -m pytest tests -v
```

## Key Features

- Secure registration/login with bcrypt password hashing + JWT
- Multi-step symptom assessment questionnaire
- Real-time ML-based risk prediction (PyTorch neural network)
- Assessment history and personal analytics (Chart.js)
- Admin dashboard with platform-wide analytics and model performance
  metrics (no individual user health data exposed)
- Role-based authorization (USER / ADMIN)
- Rate limiting on auth endpoints
- Dockerized for reproducible deployment
- Documented AWS deployment path (`docs/AWS_DEPLOYMENT.md`)

## Known Limitations

- ML model is trained on synthetic/demo data — not medically validated
- No email verification on registration
- No password reset flow
- Rate limiting is in-memory (per-instance) — a multi-instance production
  deployment would need a shared store like Redis
- `datetime.utcnow()` deprecation warnings present (non-blocking, flagged
  as a future improvement)
